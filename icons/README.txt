Icon Files for Cybersecurity Club Link Hub

Place your icon image files in this folder with the exact filenames listed below:

- whatsapp-icon.png (for WhatsApp Community and WhatsApp Channel)
- instagram-icon.png
- github-icon.png
- linkedin-icon.png
- youtube-icon.png
- discord-icon.png

Recommended specifications:
- Format: PNG (with transparent background preferred)
- Size: 256x256 pixels or 512x512 pixels (will be scaled down)
- Style: Simple, flat design or silhouette that works well when tinted

The HTML uses onerror handlers to gracefully hide missing icons, so the circular containers will remain visible with a subtle background color if an icon file is missing.
